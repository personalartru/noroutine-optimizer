Что это

Страница правит content.json в репозитории personalartru/noroutine-optimizer и коммитит его в main. Живой цикл бота сам сверяется с main каждые 45 секунд, поэтому правка попадает в следующий расчёт примерно за минуту — ждать конца круга не нужно. Уже отправленные сообщения не меняются: MAX их не редактирует, новый текст увидит тот, кто начнёт расчёт после правки. Порядок шагов, арифметика расчёта и payload'ы кнопок остаются в коде: они не отдают себя на вольный текст, иначе цифры начнут врать.

Нужен personal access token с правом Contents: Write на этот репозорий. Он хранится только в этом браузере (localStorage) и никуда, кроме GitHub API, не уходит.
